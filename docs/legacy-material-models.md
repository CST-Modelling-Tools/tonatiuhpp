# Retired Tonatiuh material models — historical technical record

## Scope and provenance

The four models below were preserved in the Tonatiuh++ repository as old,
**unbuilt** source under `source/plugins/material/`, but used the original
Tonatiuh `TMaterial`, `RandomDeviate`, and old geometry APIs. They were not
compatible with the current `MaterialRT` interface, not part of the CMake
material target, and not distributed in supported Tonatiuh++ releases.
They have now been removed from the current source tree on E1 Stage 2.

This document preserves the *intent and formulas actually visible in the old
source* rather than asserting scientific validation. The original files,
including factories, resources, Qt form editors, and copyright headers,
remain accessible through repository history before this removal. Reintroducing
any model requires a new implementation on the mandatory `MaterialRT`
probability/scattering contract, independent numerical tests, and validation
against appropriate optical data.

## Shared historical concepts

Let **d** be the incident unit direction, **n** a surface normal, and
\(\theta=\arccos[-\mathbf d\cdot\mathbf n]\) the incidence angle (front/back
normal chosen from the impact side). Specular reflection uses

\[
\mathbf d_r=\mathbf d-2(\mathbf d\cdot\mathbf n')\mathbf n',
\]

where \(\mathbf n'\) is a potentially perturbed surface normal. A traditional
single-coefficient analog roulette reflects when \(U<R\) and absorbs otherwise,
for \(U\sim\mathcal U[0,1)\). For a two-channel reflective/transmissive
material the nominal probabilities are \(P_r=R\), \(P_t=T\),
\(P_a=1-R-T\), requiring \(R,T\geq0\), \(R+T\leq1\).

The historical code offered two angular perturbation patterns:

- A *pillbox-style* cone: \(\phi=2\pi U_1\),
  \(\theta_{err}=\sigma U_2\), direction expressed relative to local
  surface-tangent axes as
  \((\sin\theta_{err}\sin\phi,\cos\theta_{err},
  \sin\theta_{err}\cos\phi)\).
- A *Gaussian slope* pattern: \(\mathbf v=(\sigma Z_1,1,\sigma Z_2)\),
  where \(Z_1,Z_2\) are generated by the legacy Box–Muller helper and then
  appropriately transformed/normalized to the scene frame.

In these four old implementations, \(\sigma\) was supplied in milliradians
and converted to radians by dividing by 1000. These expressions describe the
implemented sampling conventions, not proof of an exact microfacet BRDF.

## 1. `MaterialOneSideSpecular`

**Intent.** A mirror coating active on only the selected front or back face.
The field `isFront` determined the allowed incidence side. A ray hitting the
other side returned no continuation. On the active side, a constant scalar
`reflectivity` controlled survival; the reflection direction used the perturbed
normal \(\mathbf n'\) above. `sigmaSlope` and the distribution controlled the
local normal error.

**Intended event probabilities on enabled side:**
\(P_r=R\), \(P_a=1-R\). On the disabled side, the old implementation returned
`false` (effectively absorbing or rejecting the ray); a modern implementation
must define whether that is physical absorption or a different boundary type.

**Known limitations.** It inherited the Boolean return ambiguity and relied
on a reflectivity sensor that clamped out-of-range values rather than failing
explicitly. Normal errors and front/back behavior were not independently
validated in the current Tonatiuh++ test suite.

## 2. `MaterialStandardRoughSpecular`

**Intent.** A conventional specular mirror with *two distinct roughness/error
sources*: `sigmaSlope` perturbed the surface normal before mirror reflection,
while `sigmaSpecularity` perturbed the direction *after* reflection.
It first used a constant `reflectivity` for roulette survival.

**Nominal model:**
\[
\mathbf n'=\operatorname{normalize}\bigl(\text{local-to-world}
          (\mathbf v(\sigma_{slope}))\bigr),\qquad
\mathbf d_r=\mathbf d-2(\mathbf d\cdot\mathbf n')\mathbf n',
\]
followed by an independent direction perturbation
\(\mathbf d_o=\text{frame}(\mathbf d_r)
[\mathbf v(\sigma_{specularity})]\).
The code constructed the latter frame from \(\mathbf d_r\), the surface
normal, and their cross products.

**Nominal probabilities:** \(P_r=R\), \(P_a=1-R\). The two distinct `sigma`
fields did **not** represent independent absorption probabilities; they were
angular-scatter parameters.

**Known limitations.** The secondary cross-product frame becomes singular
when the reflected direction is parallel to the surface normal. The old code
did not guarantee robust handling of that case or check the resulting ray.
Clamping reflectivity also concealed invalid input parameters.

## 3. `MaterialAngleDependentSpecular`

**Intent.** Separate front- and back-side enable flags and tabulated
reflectivities as functions of incident angle; optional mirror-normal slope
error after selecting reflection. The tables were supplied as
\((\theta_i,R_i)\) pairs for each side. The historical helper sorted copied
data and attempted piecewise linear interpolation:

\[
R(\theta)=R_i+
    \frac{\theta-\theta_i}{\theta_{i+1}-\theta_i}
    (R_{i+1}-R_i),\quad
    \theta_i\leq\theta\leq\theta_{i+1}.
\]

The angle was capped at \(\pi/2\); on an enabled side the intended roulette
was \(P_r=R(\theta)\), \(P_a=1-R(\theta)\). A disabled side returned no
continuation. Reflections used the same perturbed-normal law as the one-sided
specular material.

**Known limitations.** The historical interpolation accessed index `i-1`
when the first tabulated sample could satisfy the interval condition, and it
could return a default zero value outside the represented range. Duplicate
angles could divide by zero. It did not consistently check table sizes,
ordering, or probability bounds. A replacement needs explicit boundary,
interpolation, and extrapolation policies; copying this routine would be unsafe.

## 4. `MaterialAngleDependentRefractive`

**Intent.** A two-sided interface whose incidence-angle tables independently
provided reflectivity \(R(\theta)\) and transmissivity \(T(\theta)\). Each
quantity was interpolated linearly using the same form as above. The old code
selected one of three outcomes using a *single* uniform draw:
\(U<R\) reflection, \(R\leq U<R+T\) transmission, otherwise absorption.
The reflection direction could receive `sigmaSlope` normal error.

**Transmission law.** With indices `nFront`/`nBack` chosen by the incoming
side, Snell's law gives

\[
n_i\sin\theta_i=n_t\sin\theta_t,
\qquad \sin^2\theta_t=(n_i/n_t)^2(1-\cos^2\theta_i).
\]

For allowed refraction the old code computed

\[
\mathbf d_t=\operatorname{normalize}\left[
  \frac{n_i}{n_t}\mathbf d_i+
  \left(\frac{n_i}{n_t}\cos\theta_i
              -\sqrt{1-\sin^2\theta_t}\right)\mathbf n
  \right].
\]

If total internal reflection was detected in the transmission calculation,
it reflected geometrically rather than refracting.

**Known limitations.** The historical roulette probability tables were not
reconciled with total internal reflection, so a nominal *transmission* event
could be turned into a geometric *reflection* after selection. It had the same
unsafe interval-indexing and missing input-validation concerns as the
angle-dependent specular model; it did not enforce \(R+T\leq1\). Thus, this
is a historical *concept*, not a validated Fresnel or energy-conserving
material implementation.

## Current supported replacements and boundary

The supported Tonatiuh++ materials are built-in `MaterialAbsorber`,
`MaterialVirtual`, `MaterialTransparent`, `MaterialRough`, and
`MaterialFresnelUnpolarized`, plus the built and packaged plugin
`MaterialSpecular`. The retired models are **not** registered, installed,
compiled or relied upon by supported tests. All supported active materials
must use the nonvirtual `MaterialRT::interact()` roulette selector, and must
report genuine absorption separately from computation errors.
